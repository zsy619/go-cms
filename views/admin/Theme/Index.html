模板文件必须为zip格式，否则无法上传
主题目录结构说明：
views目录 为模板文件，可以自定义，必须包含index.html、channel.html、category.html、article.html、search.html、tag.html、topic.html
        首页 index.html
        频道页 channel.html
        栏目页 category.html
        文章页 article.html
        搜索页 search.html
        标签页 tag.html
        专题页 topic.html
        其他模板文件可以自建
static目录 静态文件目录，包含以下目录：
        js目录 为js文件，可以自定义子文件
        css目录 为css文件，可以自定义子文件
        images目录 为模板图片，可以自定义子文件
        其他目录如fonts、plugins等，可以自定义
config.json 为主题配置文件，可以自定义，但是必须包含name、title、remark、author、version，格式如下：
        {
            "name": "default",
            "title": "默认模板",
            "description": "系统内置默认模板",
            "author": "教育网",
            "mail": "haedu@163.com",
            "version": "1.0.0"
        }
thumb.png 为主题预览图，必须有
