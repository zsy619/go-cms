常见问题

多站点如何切换？

通过 host 解析对应站点，详见 站点函数。

模板里如何调用 API？

使用 apiGet / apiPost 函数，详见 公共函数。

如何自定义主题？

复制默认主题 default 到 themes/<你的主题> 即可，详见 主题配置。

如何启用多语言？

参见 docs/i18n_design.md 完整方案，或 内置变量。
