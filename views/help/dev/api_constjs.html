const.js 文件

YYCMS 提供一个常驻的 const.min.js（const.js 的压缩版本），封装了页面常用的常量、链接生成、点击率上报等工具函数。

ℹ️

使用方式：直接在页面 <head> 引入即可，所有函数挂在 window.YYCMS 命名空间下。

3. 点击率上报函数

用于上报文章、广告、链接等点击，统一发往 /api/.../click 接口，后端异步累加计数。

📋 点击率函数3 个
函数参数说明用途
ArticleClick
  • int64 articleId文章 ID
  • string callIndex文件调用别名，为空则不记录
 文章点击率 +1
AdsClick
  • int64 ads_id广告 ID
 广告点击率 +1
LinkClick
  • int64 link_id链接 ID
 友情链接点击率 +1

4. URL 生成函数

用于在前端拼接静态化的文章/搜索/专题/标签页面 URL，避免手写路径出错。

📋 URL 生成函数4 个
函数参数说明说明
UrlForArticle
  • string call_index栏目别名
  • int64 article_id文章 ID
  • string url自定义链接（可选）
 生成文章详情页 URL
UrlForSearch
  • string keyword搜索关键词
 生成搜索结果页 URL
UrlForTopic
  • string site_flag站点标识
  • string name专题名称
 生成专题页 URL
UrlForTag
  • string site_flag站点标识
  • string name标签名称
 生成标签页 URL
