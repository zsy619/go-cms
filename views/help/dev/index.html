五、5 分钟快速接入

① 后台创建站点 → ② 绑定域名 → ③ 上传主题 → ④ 启用 API → ⑤ 前端拉数据

1) 引入前端 JS

<script src="/static/help/js/const.js"></script>
<script src="/static/help/js/cms.js"></script>

2) 调用站点信息

$.getJSON('/api/site/default', function (site) {
    console.log(site);
});

3) 拉取文章列表

$.getJSON('/api/article/list', { site_id: 1, page: 1, limit: 10 }, function (res) {
    console.log(res.data);
});

六、常见问题

❓ 多站点如何切换？

通过 host 解析对应站点（详见 站点函数）。

❓ 模板里如何调用 API？

使用 apiGet / apiPost 函数（详见 公共函数）。

❓ 如何自定义主题？

复制默认主题 default 到 themes/<你的主题> 即可。
