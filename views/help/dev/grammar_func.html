函数调用

YYCMS 提供了大量内置模板函数，可以方便地在 .html 模板中使用。下面是常用的内置函数清单，按"逻辑 / 字符串 / 类型转换 / 时间 / 视图辅助 / 配置与表单"分组。

ℹ️

调用语法：{{"{{"}} funcName arg1 arg2 ... }}，支持管道 | 串联多个函数，例如 {{"{{"}} .Time | dateformat "2006-01-02" }}。

比较运算

用于 if 内的条件判断，返回 bool。

1. eq

判断两个值是否相等。

2. ne

判断两个值是否不相等。

3. lt

判断一个值是否小于另一个值。

4. le

判断一个值是否小于等于另一个值。

5. gt

判断一个值是否大于另一个值。

6. ge

判断一个值是否大于等于另一个值。

字符串与序列化

字符串处理、HTML 转义、URL 编码、JSON 序列化。

7. html

将模板变量的 HTML 标签转义。

8. substr

截取字符串的一部分。

9. date

格式化时间和日期。

10. len

计算字符串、数组、切片或映射的长度。

11. default

如果变量为空或零值，返回默认值。

12. lower

将字符串转换为小写。

13. upper

将字符串转换为大写。

14. title

将字符串中每个单词的首字母大写。

15. add

将两个整数相加。

16. div

将两个整数相除，返回商。

17. mod

将两个整数相除，返回余数。

18. mul

将两个整数相乘。

19. urlquery

将字符串转换为 URL 查询参数的格式。

20. json

将 Go 数据结构转换为 JSON 字符串。

逻辑与函数式

and / or / call / print 等。

21. and 和 or

布尔逻辑运算。

22. call

调用一个函数。

23. index

获取数组、切片或映射的值。

24. print

输出传入的参数。

时间与文本处理

日期格式化、HTML ↔ 字符串转换。

25. dateformat

实现了时间的格式化，返回字符串

26. date

实现了类似 PHP 的 date 函数，可以很方便的根据字符串返回时间

27. compare

实现了两个对象的比较，如果相同返回 true，否者 false

28. html2str

实现了把 html 转化为字符串，剔除一些 script、css 之类的元素，返回纯文本信息

29. str2html

实现了把相应的字符串当作 HTML 来输出，不转义

30. htmlquote

实现了基本的 html 字符转义

31. htmlunquote

实现了基本的反转移字符

视图辅助与配置

表单渲染、静态资源、配置项、URL 生成、Map 取值。

32. renderform

根据 StructTag 直接生成对应的表单

33. assets_js

为 js 文件生成一个 script 标签

34. assets_css

为 css 文件生成一个 link 标签

35. config

获取 AppConfig 的值，可选的 configType 有 String, Bool, Int, Int64, Float, DIY

36. map_get

获取 map 的值

37. urlfor

获取控制器方法的 URL
