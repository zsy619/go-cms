if 判断

YYCMS 模板支持 if / else / else if 三种条件分支，并内置了 not / and / or 三种布尔运算以及 eq / ne / lt / le / gt / ge 六种比较运算。

ℹ️

结束标签：每个 if 必须有对应的 {{"{{"}} end }}；分支结构相同。
