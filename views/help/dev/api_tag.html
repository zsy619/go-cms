标签API

访问路径 参数说明 返回值 说明

/api/tag/get

 {int} limit 限制数量
{string} site_flag 站点标识
{int64} site_id 站点ID
{int64} channel_id 栏目ID 		查看 获取标签，按is_top升序排序

/api/tag/get/new

 {int} limit 限制数量
{string} site_flag 站点标识
{int64} site_id 站点ID
{int64} channel_id 栏目ID 		查看 获取最新标签，按tag_id倒序排序

/api/tag/click

 {int64} tag_id 标签ID 点击数+1

/api/tag/article/paginate

 {int} page 页码
{int} limit 每页数量
{string} tag_name 标签名称
{int64} channel_id 频道ID
{string} channel_name 频道名称
{int64} category_id 栏目ID
{string} call_index 栏目别名
{string} keyword 关键词：按标题、摘要进行搜索
{int} is_top 是否置顶
{int} is_red 是否推荐
{int} is_hot 是否热门
{int} is_slide 是否幻灯片
{int} is_search 是否搜索
{string} order_by 排序字段，为空则默认按sort_id排序，可选值：sort_id,publish_time 		查看 获取文章分页列表
