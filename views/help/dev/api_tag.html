标签开放接口

YYCMS 标签相关的 RESTful API。基础路径为 /api/tag/...。

API 列表

📋 标签开放接口 4 个接口
方法 访问路径 参数说明 返回值 说明
GET /api/tag/get
  • int limit限制数量
  • string site_flag站点标识
  • int64 site_id站点 ID
  • int64 channel_id频道 ID
 []Tag 获取标签，按 is_top 升序
GET /api/tag/get/new
  • int limit限制数量
  • string site_flag站点标识
  • int64 site_id站点 ID
  • int64 channel_id频道 ID
 []Tag 获取最新标签，按 tag_id 倒序
POST /api/tag/click
  • int64 tag_id标签 ID
 bool 标签点击数 +1
GET /api/tag/article/paginate
  • int page页码
  • int limit每页数量
  • string tag_name标签名称
  • int64 channel_id频道 ID
  • string channel_name频道名称
  • int64 category_id栏目 ID
  • string call_index栏目别名
  • string keyword搜索关键词
  • int is_top是否置顶
  • int is_red是否推荐
  • int is_hot是否热门
  • int is_slide是否幻灯片
  • int is_search是否搜索
  • string order_by排序字段，默认 sort_id，可选 publish_time
 []Article 获取标签下文章分页列表
