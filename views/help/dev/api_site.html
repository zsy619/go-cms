站点开放接口

YYCMS 站点相关的 RESTful API，支持默认站点查询、单点查询、频道、菜单、栏目导航等数据获取。 所有接口均返回 JSON，基础路径为 /api/site/... 或 /api/channel/...。

ℹ️

返回值说明: 返回结构统一为 {code, msg, count, data}，其中 code=0 表示成功。详细的 JSON 结构见下方"站点结构"、"频道结构"、"菜单结构"。

📦 站点结构

单条 Site 对象的数据结构，对应 GET /api/site/default 和 /api/site/find 的 data 字段。

📦 频道结构

[]Channel 数组的元素结构，对应 /api/channel/get 接口的 data 字段。

📦 菜单结构

[]Nav 树形结构（带 children 子菜单数组），对应 /api/site/menu 接口。
