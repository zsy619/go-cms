在这个示例中，.Condition 是每个数据项的属性，该属性的值被用于 switch 语句。如果 .Condition 的值等于 "option1"，则会输出 "Option 1 selected"。如果 .Condition 的值等于 "option2"，则会输出 "Option 2 selected"。如果 .Condition 的值既不是 "option1" 也不是 "option2"，则会输出 "No option selected"。

注意，switch 语句中的 default 分支是可选的，如果没有 default 分支并且没有匹配的 case 分支，switch 语句将不会输出任何内容。
