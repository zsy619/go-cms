switch 判断

YYCMS 模板没有 Go 原生的 switch 关键字，但可以使用 if / else if / else 组合，配合 eq 函数模拟 switch / case 语义。

ℹ️

default 分支：对应 {{"{{"}} else }}；没有 default 时若所有 case 都不匹配则不输出。
