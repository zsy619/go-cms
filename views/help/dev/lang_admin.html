语言设置（管理端）

CMS 系统支持多语言管理，通过语言设置功能可以管理站点支持的所有语言，包括简体中文、English、日本語、한국어 等全球主流语言。

📍 入口位置

路径：站点管理 → 语言设置

URL：/admin/site/language

✨ 功能特性

  • 🌍 内置 197 种语言（含 emoji 国旗图标）
  • 🔍 支持按名称/代码搜索
  • 📝 支持新增、编辑、删除语言
  • 📊 支持排序、启用/禁用
  • ⭐ 支持设置默认语言
  • 🚀 一键初始化语言数据

📊 数据表结构

cms_language 表存储所有语言配置信息。

🔌 API 接口

📋 后台管理接口8 个
URL方法说明
/admin/site/language GET 语言设置列表页面
/admin/site/language/data GET 获取语言列表数据（不分页）
/admin/site/language/edit GET 语言编辑页面
/admin/site/language/save POST 保存语言（新增/修改）
/admin/site/language/delete GET 删除语言（支持批量，参数 ids）
/admin/site/language/sort GET 更新排序（参数 id, sort_id）
/admin/site/language/status GET 切换状态（参数 id, status）
/admin/site/language/init GET 初始化语言数据（内置 197 种）
