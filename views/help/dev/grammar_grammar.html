模板语法

YYCMS 模板引擎兼容 Go 标准库 html/template 与 text/template，统一使用 {{"{{"}} }} 作为左右标签，没有其它标识符。

ℹ️

转义提示：在 Markdown / HTML 中输出模板示例需用 {{"{{"}}{{"{{"}} }} 或反引号包裹，避免被引擎提前解析。

核心语法

  • 使用 . 访问当前位置的上下文
  • 使用 $ 引用当前模板根级的上下文
  • 使用 $var 访问创建的局部变量

支持的 Go 字面量

Pipeline 管道

Pipeline 可以是上下文变量输出，也可以是函数通过管道传递的返回值。
