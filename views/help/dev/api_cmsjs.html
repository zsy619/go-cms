cms.js 文件

YYCMS 提供一个常驻的 cms.min.js，是对所有业务 RESTful API 的 Promise 化封装，对应命名空间 YYCMS.cms.Article / YYCMS.cms.Site / YYCMS.cms.Ads / YYCMS.cms.Link / YYCMS.cms.Category 等。

ℹ️

使用方式：站内直接引入，站外需先声明 cmsSite 后再引入。详见下方。

1. 引用方式

站内引用

站外引用

站外页面需要在引入之前先声明 cmsSite 变量，指向 CMS 站点的根 URL（含协议）。

引入后即可使用 YYCMS.cms.Article.get({...}, {beforeSend, success, complete}) 等方法。
