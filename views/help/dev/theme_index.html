index 页面

首页模板是站点访问量最大的页面，通常包含顶部导航、轮播、推荐栏目、热点文章列表、底部友链等区块。page.htm（或 index.html）是默认的首页模板文件，也可以通过后台"主题设置 → 首页模板"指定独立模板。

ℹ️

模板变量：.site 站点信息、.channel 频道列表、.articles 最新文章等。

推荐结构

  • 顶部：{{"{{"}} template "_top.html" . }}
  • 菜单：{{"{{"}} template "_menu.html" . }}
  • 轮播：使用 {{"{{"}} AdsTop 5 }} 取置顶广告
  • 推荐栏目：{{"{{"}} range ArticleNewExtend 8 1 1 0 "" 0 0 0 0 "" }}
  • 底部：{{"{{"}} template "_bottom.html" . }}
