广告函数

模板内可调用的广告相关函数，对应 const.js 中同名函数的服务端实现。

📋 广告函数4 个
api 名称需要参数返回值说明
AdsNew
  • int limit获取数量（≤0 按 6 条）
 []*ApiAdsModel 获取最新广告列表
AdsNewExtend
  • int limit获取数量
  • int64 site_id站点 ID
  • string site_flag站点标识
  • int64 category_id广告分类 ID
  • string call_index广告分类标识
 []*ApiAdsModel 获取最新广告列表（带过滤）
AdsTop
  • int limit获取数量
 []*ApiAdsModel 获取广告列表（按 is_top 排序）
AdsTopExtend
  • int limit
  • int64 site_id
  • string site_flag
  • int64 category_id
  • string call_index
 []*ApiAdsModel 获取广告列表（带过滤）

📦 ApiAdsModel 结构

广告对象，对应数据库 cms_ads 表。
