路径函数

路径函数

api名称 需要参数 返回值 说明

UrlForArticle

 {string} call_index 栏目别名
{int64} article_id 文章ID
{string} url 自定义链接 		如url为空，返回/article/:call_index/:article_id 文章链接

UrlForArticleExtend

 {string} flag 站点标识
{string} name 频道名称
{string} call_index 栏目别名
{int64} article_id 文章ID 		/:flag/:name/:call_index/:article_id 文章链接

UrlForCategory

 {string} call_index 栏目别名 栏目链接

UrlForCategoryExtend

 {string} flag 站点标识
{string} name 频道名称
{string} call_index 栏目别名 		栏目链接

UrlForChannel

 {string} name 频道名称 频道链接

UrlForTopic

 {string} name 专题名称 专题链接

UrlForTag

 {string} name 标签名称 标签链接

UrlForSearch

 {string} keyword 关键词 搜索链接

UrlForView

 {string} theme 主题名称，如defalut、h5、pc等，对应views/themes目录下的文件夹，区分大小写
{string} file 视图名称 如index.html、list.html等，对应views/themes/主题名称/views目录下的文件 		string 获取模板路径
