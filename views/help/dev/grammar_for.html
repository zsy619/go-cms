循环

使用 {{"{{"}} range }} 和 {{"{{"}} end }} 来实现循环遍历。可以用于遍历数组、切片、映射等。

ℹ️

语法：{{"{{"}} range pipeline }}...{{"{{"}} end }}；支持 $index / $key, $value 变量。

1.遍历数组或切片：

在这个例子中，.Items 是一个数组或切片，{{"{{"}} range .Items }} 遍历每个元素，{{"{{"}} . }} 输出当前元素的值。

2.遍历映射：

在这个例子中，.ItemsMap 是一个映射，{{"{{"}} range $key, $value := .ItemsMap }} 遍历每个键值对，$key 和 $value 分别表示当前的键和值。

3.在循环中使用索引：

在这个例子中，{{"{{"}} range $index, $element := .Items }} 遍历每个元素，同时获取其索引值（从 0 开始），$index 表示当前元素的索引，$element 表示当前元素的值。
