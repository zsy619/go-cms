站点函数

模板内可直接调用的站点相关函数，对应 const.js 中同名前端函数的服务端实现。

📋 站点函数4 个
api 名称需要参数返回值说明
SiteDefault 无 *ApiSiteModel 默认站点
SiteChannel 无 []*ApiChannelModel 站点频道
SiteMenu
  • int64 site_id站点 ID
 []*ApiNavModel 站点菜单
SiteMenuFlag
  • string site_flag站点标识
 []*ApiNavModel 通过标识获取菜单

📦 ApiSiteModel 结构

站点对象，对应数据库 cms_site 表。

📦 ApiNavModel 结构

菜单对象，递归树形结构（children 为子菜单）。

📦 ApiChannelModel 结构

频道对象，对应数据库 cms_channel 表。
