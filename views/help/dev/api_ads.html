广告开放接口

YYCMS 广告相关的 RESTful API，支持获取广告列表、最新广告、分页广告、点击数统计等。 基础路径为 /api/ads/...，返回 JSON。

ℹ️

参数说明: site_id 与 site_flag 二选一即可；category_id 与 call_index 用于广告位定位，传入其一即可。
