内置变量

所有模板都可以直接访问的全局变量，命名空间以 $ 开头（如 $.siteTheme）。

📋 内置变量9 个
变量返回值说明
siteTheme string 默认站点模板名称
siteStatic string 站点静态路径：/views/themes/{{"{{"}}$.siteTheme}}/static/
siteImages string 站点静态图片路径：/views/themes/{{"{{"}}$.siteTheme}}/static/images/
siteJs string 站点静态 JS 路径：/views/themes/{{"{{"}}$.siteTheme}}/static/js/
siteCss string 站点静态 CSS 路径：/views/themes/{{"{{"}}$.siteTheme}}/static/css/
siteViews string 站点 views 路径：/views/themes/{{"{{"}}$.siteTheme}}/views/
site *ApiSiteModel 当前站点信息
channel []*ApiChannelModel 站点频道信息
year int 年份（例：2024）
ℹ️

调用方式：模板中可直接使用 {{"{{"}}.site.Company}} 访问站点公司名；页面顶部标题可用 {{"{{"}}.site.Title}}。
