主题的基本信息详解

在制作主题模板时，常常需要显示主题图片与一些描述信息。本节说明主题打包的标准结构与 config.json 字段。

ℹ️

主题安装位置：/views/themes/{name}/，打包为 zip 后通过后台"主题管理"上传即可启用。

1. config.json

主题根目录的 config.json 用于描述主题元数据，字段语义清晰、便于搜索引擎收录。

2. 图片信息

主题需要一张 thumb.png 作为缩略图，建议尺寸 800×600，最大不超过 2MB。

3. 皮肤目录结构

标准主题目录结构：

📋 目录约定4 个顶层目录
目录用途
config.json主题元数据（必填）
thumb.png主题缩略图（必填）
static/静态资源（CSS / JS / 图片）
views/模板文件（公共 + 业务页）
💡

小贴士：views/_top.html、_bottom.html、_menu.html 三个文件是公共模板，会被 index.html 等业务页 {{"{{"}} template " 引用。
