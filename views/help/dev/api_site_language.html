站点语言 API

站点语言 API 用于查询站点（cms_site）与语言（cms_language）的关联信息，是多语言站点的核心数据接口。

🔍 关联查询 SQL

📊 数据模型

SiteLanguage 视图模型

关联查询返回的字段结构。

CMS 数据库表

涉及两张表：

  • cms_site - 站点主表（含 language_code 字段）
  • cms_language - 语言设置表

📡 API 接口

📋 站点语言接口3 个
URL方法说明
/api/site/language/list GET 获取所有站点语言关联（按 is_default 降序）
/api/site/language/find GET 根据站点ID获取语言信息（参数 site_id）
/api/site/language/by-code GET 根据语言代码查询站点（参数 code）

⚠️ 注意事项

  • 接口仅返回已配置语言（language_code）的站点数据
  • 未配置语言的站点不会出现在结果中
  • 使用 utf8mb4 字符集以支持 emoji 图标
  • 排序规则：默认语言优先（is_default DESC）
