article 页面

文章详情页模板，对应数据库 cms_article 表的完整内容渲染。包括文章标题、正文、相册、附件、上一篇/下一篇、相关文章等。

ℹ️

上下文变量：.Article 当前文章完整模型、.Album 相册列表、.Attach 附件列表、.PrevNext 上下篇。

推荐结构

  • 面包屑：{{"{{"}} .Category.Title }}
  • 标题：{{"{{"}} .Article.Title }}
  • 发布时间：{{"{{"}} dateformat .Article.PublishTime "2006-01-02 15:04" }}
  • 来源 / 作者：{{"{{"}} .Article.Source }} / {{"{{"}} .Article.Author }}
  • 正文：{{"{{"}} str2html .Article.Content }}
  • 相册 / 附件：{{"{{"}} range .Album }} / {{"{{"}} range .Attach }}
  • 上一篇 / 下一篇：{{"{{"}} if .PrevNext.Prev }}...
