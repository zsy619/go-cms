文章开放接口

YYCMS 文章与栏目相关的 RESTful API。基础路径为 /api/article/... 和 /api/category/...。

ℹ️

说明: call_index 与 article_id 在查询文章详情时二选一即可。前端组合查询时建议同时传两个参数以便容错。

栏目导航 API

📋 栏目导航1 个接口
方法访问路径参数说明返回值说明
GET /api/category/nav
  • string channel_name频道名称
  • int64 channel_id频道 ID
  • string call_index栏目别名
  • int64 category_id栏目 ID
  • int64 article_id文章 ID
 []Nav 获取栏目导航

栏目 API

📋 栏目3 个接口
方法访问路径参数说明返回值说明
GET /api/category/get
  • string channel_name频道名称
 []Category 通过频道名称获取栏目列表
GET /api/category/get
  • string channel_name频道名称
  • string call_index栏目别名
 []Category 通过频道+栏目别名获取列表
GET /api/category/find
  • int64 category_id栏目 ID
  • string call_index栏目别名
 Category 获取栏目详情

文章 API

📋 文章11 个接口
方法访问路径参数说明返回值说明
GET /api/article/get
  • int limit获取数量，默认 6
  • int64 channel_id频道 ID
  • int64 category_id栏目 ID
  • string call_index栏目别名
  • int is_top是否置顶
  • int is_red是否推荐
  • int is_hot是否热门
  • int is_slide是否幻灯片
  • string order_by排序字段
  • bool is_cache是否使用缓存
 []Article 获取文章列表
GET /api/article/get/new
  • int limit获取数量
  • int64 channel_id频道 ID
  • int64 category_id栏目 ID
  • string call_index栏目别名
  • int is_top/is_red/is_hot/is_slide过滤标志
  • string order_by排序字段
 []Article 获取最新文章列表
GET /api/article/paginate
  • int limit每页数量
  • int64 channel_id频道 ID
  • int64 category_id栏目 ID
  • string call_index栏目别名
  • string keyword搜索关键词
  • int is_top/is_red/is_hot/is_slide过滤标志
  • string order_by排序字段
 []Article 分页获取文章列表
GET /api/article/find
  • string call_index调用别名
  • int64 article_id文章 ID
 ArticleDetail 获取文章详情、相册、附件
GET /api/article/prev_next
  • string call_index栏目别名
  • int64 category_id栏目 ID
  • int64 article_id文章 ID
 PrevNext 获取文章上一篇、下一篇
GET /api/article/article
  • string call_index调用别名
  • int64 article_id文章 ID
 Article 获取文章详情（不含附件、相册）
GET /api/article/album
  • string call_index调用别名
  • int64 article_id文章 ID
 []Album 获取文章相册列表
GET /api/article/attach
  • string call_index调用别名
  • int64 article_id文章 ID
 []Attach 获取文章附件列表
POST /api/article/click
  • string call_index调用别名
  • int64 article_id文章 ID
 bool 文章点击数 +1
POST /api/article/like
  • string call_index调用别名
  • int64 article_id文章 ID
 bool 文章点赞数 +1
POST /api/article/album/click
  • int64 article_id文章 ID
  • int64 ablum_id图片 ID
 bool 文章相册点击数 +1
GET /api/article/property
  • int64 parentId父 ID
  • int64 articleId文章 ID
  • int64 callIndex属性别名
  • int64 title属性名称
 []Property 获取内容自定义属性列表
